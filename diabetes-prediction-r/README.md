Diabetes Prediction using Logistic Regression in R.
This project analysis Pima Indians Diabetes dataset using logistic Regression. The main purposes were handle missing values using different imputation methods, exploting medical variable distributions and comparing multiple regression models and lastly evaluating models by using ROC and AUC. 

    The methods: Regression imputation, PMM (by MICE), KNN Imputation, Logistic Regression, ROC/AUC evaluation. 

The results: 
Baseline logistic Regression showed - AUC=0.864
Log-Transformed Insulin model - AUC=0.870
Model without Insulin - AUC=0.863

The whole analysis was created by R.
